# Dominant System

Web de **Dominant System**, mi marca de desarrollo web para negocios locales de la Sierra de Madrid.

Desarrollado con IA (Claude Code) bajo mi dirección: defino la estructura y el diseño, reviso el código y hago las pruebas.

## Web publicada

**https://dominant.es/**

## Tecnologías

- HTML5, CSS3 y JavaScript, sin frameworks
- Reserva de llamadas integrada con Cal.com
- SEO local: metaetiquetas, datos estructurados (JSON-LD), sitemap y blog
- Cabeceras de seguridad (`_headers`): CSP, HSTS y otras

## Páginas

- `index.html`: portada con servicios, proyectos y contacto
- `sobre-mi.html`, `precios.html`
- `blog.html` y artículos en `blog/`
- Textos legales: aviso legal, privacidad, cookies y términos
